Vibe Coding 止步于控制开始的地方

Vibe Coding 式开发者，就是敲下一个 prompt 然后祈祷。专业地使用 Claude Code，则是准确知道这个工具将要做什么。同时还能把它证明出来、重放出来，并交给一个团队。本课程沿着十二个控制杠杆展开，顺序就是开发者应当逐一掌握它们的顺序：先是安全，然后是记忆和命令，接着是委派给子代理，最后是在团队层面扩展。

  • 「我让它跑着，然后听天由命」→明确的权限范围、启用的沙箱、纳入版本管理的规则
  • 「每次会话都要把上下文重讲一遍」→CLAUDE.md + 自动记忆，加载与审查都通过 /context
  • 「我凭记忆一遍遍重敲同一个 prompt」→一个 /name 命令，纳入版本管理，位于 .claude/skills/
  • 「只有一条线程，什么都混在一起」→隔离的子代理、按任务选择模型、受控的调用深度
  • 「我希望它会去格式化并跑测试」→确定性的 hooks，总是在正确的时机执行
