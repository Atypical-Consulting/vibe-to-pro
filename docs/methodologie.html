Comment ce cours vérifie chaque fait qu'il enseigne.

Ce cours n'est pas écrit de mémoire. Il part du CHANGELOG officiel de Claude Code et fait passer chaque fonctionnalité candidate par un circuit de vérification avant qu'elle ne devienne une ligne du cours.

Le circuit

1

Extraire

Les 385 versions du CHANGELOG (de la 0.2.21 à la 2.1.260) sont découpées et passées en revue pour en isoler les fonctionnalités majeures — pas les correctifs mineurs ni les changements internes.

2

Vérifier

Chacune des 395 fonctionnalités candidates est confrontée, indépendamment, à la documentation actuelle sur code.claude.com par une recherche dédiée — pas par rappel de mémoire du modèle.

3

Classer

Chaque fait reçoit un verdict : confirmé (316, inchangé depuis), mis à jour (55, le comportement a évolué depuis la version du changelog), ou non vérifiable (24, écarté).

4

Curer

Sur les 371 faits confirmés ou mis à jour, 98 ont été retenus dans les 14 modules du cours — sélectionnés pour leur pertinence pédagogique et pour garder chaque module lisible, pas parce que le reste serait faux.

Ce qui a été écarté

24 fonctionnalités candidates n'ont pas pu être confirmées contre la documentation actuelle — orthographe différente, page disparue, comportement changé sans trace claire. Elles ne figurent nulle part dans le cours, plutôt que d'y être présentées comme acquises.

Voir 3 exemples réels de faits écartés, sur les 24
  • non vérifiable« Commande /approved-tools » (v0.2.26) — le changelog historique la mentionne, mais aucune page actuelle ne la documente ; elle semble avoir été renommée en /permissions à une étape ultérieure, sans confirmation directe du lien entre les deux.
  • non vérifiable« Les sous-agents continuent de travailler après un refus de permission, en tentant une approche alternative » (v2.1.0) — plausible et cohérent avec le fonctionnement agentique général, mais aucune source officielle ne décrit ce comportement précis.
  • non vérifiable« Les résultats de l'outil Agent incluent le nombre de tokens, le nombre d'appels d'outils et la durée » (v2.1.30) — aucune page de référence des outils ne mentionne explicitement ces trois métriques dans la sortie de l'outil.

Limites assumées

La vérification s'appuie sur la documentation publique à un instant donné (2 septembre 2026, Claude Code v2.1.260). Claude Code publie de nouvelles versions plusieurs fois par semaine : un détail exact aujourd'hui peut changer demain. Chaque fait du cours affiche sa date de vérification — confirmez toujours avec claude --version et la documentation en vigueur avant de vous y fier en production.
