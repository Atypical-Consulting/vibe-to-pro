Methodology

How this course verifies every fact it teaches.

This course isn't written from memory. It starts from the official Claude Code CHANGELOG and runs every candidate feature through a verification pipeline before it becomes a line in the course.

The pipeline

1

Extract

All 385 CHANGELOG releases (0.2.21 to 2.1.260) are split up and reviewed to isolate major features, not minor fixes or internal changes.

2

Verify

Each of the 395 candidate features is checked, independently, against current documentation on code.claude.com through a dedicated search, never from the model's memory.

3

Classify

Every fact gets a verdict: confirmed (316, unchanged since), updated (55, behavior has evolved since the changelog entry), or unverifiable (24, discarded).

4

Curate

Of the 371 confirmed or updated facts, 98 were kept across the 14 course chapters. They're chosen for pedagogical relevance and to keep each chapter readable, not because the rest would be false.

What got discarded

24 candidate features couldn't be confirmed against current documentation: different spelling, a page that's gone, behavior changed without a clear trace. They appear nowhere in the course, rather than being presented as settled.

See 3 real examples of discarded facts, out of 24
  • unverifiable"The /approved-tools command" (v0.2.26): the historical changelog mentions it, but no current page documents it; it seems to have been renamed to /permissions at a later stage, with no direct confirmation of the link between the two.
  • unverifiable"Sub-agents keep working after a permission denial, by trying an alternative approach" (v2.1.0): plausible and consistent with general agentic behavior, but no official source describes this specific behavior.
  • unverifiable"Agent tool results include token count, tool call count, and duration" (v2.1.30): no tool reference page explicitly mentions these three metrics in the tool's output.

Known limits

Verification relies on public documentation at a given point in time (September 2, 2026, Claude Code v2.1.260). Claude Code ships new releases several times a week, so an exact detail today can change tomorrow. Every fact in the course shows its verification date: always confirm with claude --version and the current documentation before relying on a specific detail in production.
