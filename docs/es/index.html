00 · El diagnóstico

Un prompt que funciona no es una práctica.

El vibe-coding produce resultados, pero ninguna garantía: sin perímetro de permisos, sin registro, sin red de seguridad en caso de error. Aquí está la misma intención, tratada de dos maneras.

vibe-coding
$ claude

práctica profesional
$ claude --permission-mode plan

01 · El método

Nada se enseña sin haber sido verificado.

Este curso no se escribe de memoria. Cada dato sigue el mismo circuito antes de convertirse en una línea del curso:

1

Extraer

Las 385 versiones del CHANGELOG oficial se dividen y se revisan para aislar las funciones principales, no las correcciones menores.

2

Verificar

Cada función candidata se contrasta, de forma independiente, con la documentación actual en code.claude.com mediante una búsqueda específica.

3

Decidir

Cada dato recibe un veredicto: confirmado, actualizado (el comportamiento cambió desde entonces), o no verificable.

4

Descartar o publicar

Solo los datos confirmados o actualizados entran en el curso, con la fuente citada. El resto se descarta, nunca se presenta como un hecho establecido.
